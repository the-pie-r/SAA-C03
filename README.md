# AWS Certified Solutions Architect — Associate: Day-by-Day Schedule with Labs

Same content as the original syllabus — nothing in the modules, learning objectives, or topics has been changed. The Hands-on Lab column below is copied only from the "Practical Assignment" sections that exist in the source docx — nothing added. Where the docx has no Practical Assignment for a session (assessment/discussion sessions), it's marked as not listed.

| Day | Topics Covered | Duration | Hands-on Lab |
|-----|------------------|----------|----------------|
| Day 1 | Module 1: Introduction to AWS & Cloud Fundamentals — Understand core cloud computing concepts and deployment/service models; Explain AWS value proposition and global infrastructure; Differentiate AWS pricing models and support plans; Understand the AWS Shared Responsibility Model; Set up and secure an AWS account | 1.5 -3  hrs | Create a new AWS Free Tier account with MFA enabled on the root user; Explore the AWS Management Console and identify at least 10 core services across categories; Set a billing alarm and budget notification to track Free Tier usage; Use the AWS Pricing Calculator to estimate the monthly cost of a simple 2-tier web application |
| Day 2 | Module 2: Compute Services — Part 1 (EC2, Load Balancing & Auto Scaling) — Launch and configure EC2 instances with AMIs and security groups; Design highly available architectures using Elastic Load Balancing; Configure Auto Scaling to handle variable workloads | 1.5 -3  hrs | Launch an EC2 instance from a public AMI, connect via SSH, and host a simple web page; Create a custom Security Group allowing only HTTP/HTTPS and SSH from a specific IP; Deploy an Application Load Balancer in front of two EC2 instances across two AZs; Configure an Auto Scaling Group with a target-tracking policy and simulate load to observe scale-out/scale-in |
| Day 3 | Module 3: Compute Services — Part 2 (Elastic Beanstalk, Lambda & Fargate) — Deploy a web application using Elastic Beanstalk; Understand serverless computing and build a basic Lambda function; Differentiate container orchestration using ECS/EKS with Fargate | 1.5 -3  hrs | Deploy a sample web application using Elastic Beanstalk and perform a rolling update; Write and deploy a Lambda function; Work with ECS |
| Day 4 | Module 4: Networking & Content Delivery — Part 1 (VPC & Peering) — Design a custom VPC with public and private subnets; Control traffic flow using route tables, NACLs, and security groups; Connect two VPCs using VPC Peering | 1.5 -3  hrs | Design and build a custom VPC with 2 public and 2 private subnets across two AZs; Configure route tables, an Internet Gateway, and a NAT Gateway for private subnet internet access; Create custom NACLs to restrict traffic and compare behavior with Security Groups; Establish a VPC Peering connection between two VPCs and verify connectivity with a ping/curl test |
| Day 5 | Module 5: Networking & Content Delivery — Part 2 (Direct Connect, Route 53 & CloudFront) — Understand dedicated network connectivity options to AWS; Configure DNS routing and domain management using Route 53; Accelerate content delivery globally using CloudFront | 1.5 -3  hrs | Register/configure a hosted zone in Route 53 and create A and CNAME records for a sample domain; Configure a Weighted or Latency-based routing policy across two EC2 endpoints; Create a CloudFront distribution in front of an S3 static website and test edge caching; Set up a Route 53 health check with failover routing between a primary and backup endpoint |
| Day 6 | Module 6: Storage Services — Part 1 (S3 & S3 Glacier) — Create and manage S3 buckets with appropriate access controls; Apply storage classes and lifecycle policies to optimize cost; Understand archival strategies using S3 Glacier | 1.5 -3  hrs | Create an S3 bucket, upload objects, and enable versioning; Configure a lifecycle; Host a static website using S3 and configure a bucket policy for public read access |
| Day 7 | Module 7: Storage Services — Part 2 (EBS, EFS, Storage Gateway & Snowball) — Differentiate block, file, and object storage use cases; Configure EBS volumes, snapshots, and backup strategies; Understand hybrid and large-scale data migration options | 1.5 -3  hrs | Create and attach an EBS volume to an EC2 instance, format it, and take a manual snapshot; Restore a volume from a snapshot to a new EC2 instance in a different AZ; Set up an EFS file system and mount it on two EC2 instances to demonstrate shared access; Walkthrough exercise (simulated): plan a Storage Gateway or Snowball migration scenario for a given dataset size |
| Day 8 | Module 8: Live Assessment I — Proctored assessment covering Classes 1–7: Cloud Fundamentals, Compute Services, Networking, and Storage | 1.5 -3  hrs | (Assessment session) |
| Day 9 | Module 9: Databases — Part 1 (RDS & DynamoDB) — Deploy and manage a relational database using Amazon RDS; Design a NoSQL data model and work with DynamoDB | 1.5 -3  hrs | Launch a Multi-AZ RDS MySQL/PostgreSQL instance and connect from an EC2 client; Create a DynamoDB table |
| Day 10 | Module 10: Databases — Part 2 (ElastiCache, Redshift & RDS Proxy) — Improve application performance using in-memory caching; Understand data warehousing concepts with Redshift; Manage database connections efficiently using RDS Proxy | 1.5 -3  hrs |  |
| Day 11 | Module 11: Security & Identity Management — Part 1 (IAM, MFA & Organizations) — Implement least-privilege access control using IAM; Secure user accounts with Multi-Factor Authentication; Manage multiple AWS accounts using AWS Organizations | 1.5 -3  hrs | Create IAM users and groups; write a custom policy granting access to only a specific S3 bucket; Enable MFA on an IAM user and enforce it via an IAM policy condition; Create an IAM Role for an EC2 instance to access S3 without embedding credentials; (Simulation) Design an AWS Organizations structure with OUs for Dev, Test, and Prod, and draft a sample SCP |
| Day 12 | Module 12: Security, Compliance & Governance (CloudTrail, Config, Secrets Manager & Security Hub) — Track and audit API activity using CloudTrail; Monitor resource configuration compliance using AWS Config; Securely manage secrets and encryption keys; Get a centralized security posture view using Security Hub | 1.5 -3  hrs | Enable CloudTrail across all regions and locate a specific API call (e.g., a security group change) in the logs; Create an AWS Config rule to detect S3 buckets without encryption enabled and review compliance results |
| Day 13 | Module 13: Live Assessment II — Proctored assessment covering Classes 9–12: Databases and Security & Governance | 1.5 -3  hrs | (Assessment session) |
| Day 14 | Module 14: Monitoring & Optimization — Monitor infrastructure health using CloudWatch; Use CloudTrail's event history for auditing; Optimize AWS spend and follow best-practice recommendations (Trusted Advisor, Cost Explorer, Budgets) | 1.5 -3 hrs | Create a CloudWatch custom metric and configure an alarm that notifies via SNS on threshold breach; Build a CloudWatch Dashboard consolidating EC2, RDS, and ELB metrics; Set up an AWS Budget with an alert threshold at 80% of the monthly budget |
| Day 15 | Module 15: Live Assessment III — Proctored assessment covering Class 14 (Monitoring & Optimization) plus a cumulative review of prior modules | 1.5 -3  hrs |  (Assessment session) |
| Day 16 | Module 16: High Availability, Fault Tolerance, and Disaster Recovery — Design architectures that remain available under component failure; Differentiate high availability from fault tolerance and disaster recovery; Select the appropriate DR strategy for a given RTO/RPO; Cross-Region replication strategies | 1.5 -3 hrs | Lab on situation based |
| Day 17 | Module 17: Application Integration — Decouple application components using messaging and notification services; Design event-driven architectures using EventBridge; Choose between SNS, SQS, Amazon MQ, and EventBridge | 1.5 -3 hrs | Create an SNS topic and subscribe an email endpoint and an SQS queue (fan-out pattern) |

| Day 18 | Module 18: Exam Preparation & Practice — Understand the exam format, domains, and scoring methodology; Practice with realistic, scenario-based sample questions; Build a personalized exam-day strategy |  hrs |  |
| Day 19 | Module 19: Global Exam Paper Discussion — Guided, question-by-question review of a global/practice exam paper; Clarify doubts on tricky, scenario-based questions; Reinforce concepts through peer discussion and instructor explanation | 1.5 -3 hrs | |
| Day 20 | Module 20: Live Assessment IV (Final Mock Assessment) — Full-length, proctored mock assessment simulating the complete AWS Certified Solutions Architect – Associate exam experience across all domains | 1.5 -3 hrs |  (Assessment session) |
